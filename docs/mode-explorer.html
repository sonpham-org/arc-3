The turn message, by mode

At the start of each turn the harness sends the model a user message; today that is always the same one, the Stock prompt. Each mode below is Stock with a short focus for that turn. Every mode has a version built on Son's current notebook and one built on Daniel Franzen's current public notebook. All wording is a draft for Son to edit. The Stuck levels tab lists, per game, the first level our runs stop clearing reliably; open a game to line up modes for that point and press Play to run the scheme on the two DGX Sparks from a recorded run's position at the start of that level. Results show under the game for everyone signed in.
