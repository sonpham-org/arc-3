How to use this page
  1. Sign in to the site. Play, Cancel and editing modes need it.
  2. Pick a game from the list on the left (a strip across the top on a phone), then pick a level. A level's fill shows how often stock runs clear it; the dot or ring marks a level Play can start from (hover a level for details).
  3. Choose Carry context or No context next to Play: keep what an earlier run learned before this level, or start the level fresh like a new game.
  4. Build the queue: drag modes from the bar into the queue (on a phone, tap a mode to add it). One mode runs per turn, in order; Stock plays every turn after the queue. The gear changes one turn's settings.
  5. Press Play. The Sparks run one job at a time, so yours may wait in line; its place is shown. Results appear under Play, and every run records the exact wording of each mode it used.
  6. Change the modes themselves: the pencil on a mode edits it for everyone (each save is a new version); New mode adds one. A mode is only its instructions for the turn it runs, added at the end of the turn message; the system prompt and the turn facts the harness fills in stay as they are. Prompts shows all three parts, and Preview request shows the exact request Play would send.

For a guided tour with a demo, press ? next to Queue and Prompts. It never starts a run or saves anything.
