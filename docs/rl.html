The Kaggle model, learning from its own wins

01

Is it getting better?

Each dot is one run of a panel: every game in it played once, levels added up. The left column is the model before training; each round of training adds a column. The model is learning when the dots climb from column to column, on the held-out games as well as the trained ones.

02

One lap of the loop

Play, keep the winning turns, train, put the new weights back into the notebook, test them against the old ones. The test runs of one round are the plays of the next.

measuredestimatehappening now
03

Training, record by record

Each record is one game's history, up to 120k tokens. Only the turns that cleared a level carry loss: the model is pushed to say again what it said when it won.

A record is scored before the model has trained on it: one pass, nothing repeated. So the glowing line falling means the lessons carry over to records it has not seen yet (partly within a game, since one game's records overlap).
04

What it is learning from

The 14 training games. Each bar segment is a level: lit once if one of the two source runs cleared it, bright if both did. The thin bar fills as that game's records go through training.

05

Every play, live

The runs behind section 01. Each game is played 5 or 6 times at once in one run, the same load as a full 25-game run. One lane per model; a dot is one play at the level it reached, a hollow dot is still playing, the tick is the mean.

Game ids are opaque on purpose. Every test run uses the no-border notebook; held-out games are never trained or rated.
