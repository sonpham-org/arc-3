RL v2 · one mode per turn

A coach that picks how the next turn is played

At every new turn the coach picks a mode: a one-line focus added to the turn message, plus a thinking budget, a move cap and a temperature. Builds are the harness and coach versions; decisions are the modes it picked, turn by turn; the tree puts every run of a game on one tree from the game start, each turn coloured by its mode; training is the RL campaign that learns which mode to pick where.

01

Builds

Each card is one build: a harness, or a coach on top of its parent. The big number is the mean all-25 score over finished runs; under a child, the change against its parent. The small chips are single runs; a run still playing shows its minute. Click a run with decisions to inspect it.

02

Decisions

One run, one game: every mode the coach picked, in order. The strip shows the whole game at a glance (a tick marks a turn that cleared a level, a dark base a game over). Click a row for everything the coach saw.

03

Tree

One game, every run on one tree from the same root: the game start. Left to right is the game moves (or turns) since the start; each edge is the turns that went from one node to the next, thicker when more runs took it, coloured by the coach mode of those turns (stock in light grey). Pick what counts as one node: the exact path, or the same screen (after the same number of moves, in the level, anywhere, or in bands of 6 moves); the looser the node, the more the runs merge. A tick with a number marks a cleared level, a red mark a game over, a "restart" badge an RL rollout that began from a saved state in the middle of the tree. Hover an edge for its turns, a run for its whole path; click a node for its steps by mode, and an edge to read each turn. "Goal held" underlines each turn with the goal the model held then, where the trace grader judged it: green right, amber partly right, red wrong.

04

Training

The RL campaign on the rollout server. A node of the tree is restored once and played by 5 sibling tries: try 0 plays stock, the others start with an assigned mode and then follow the current policy. After each round the learner compares the siblings at each node, moves the policy toward the faster ones and picks the next nodes.
