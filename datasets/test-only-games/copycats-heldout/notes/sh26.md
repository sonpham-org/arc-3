# sh26 — copy of sb26 Sequence Belt (HELD-OUT, TEST ONLY — NEVER TRAIN)

**Kept.** The original rule code, copied programmatically: click a tray piece to pick it up,
click an empty slot to place it or a machine piece to swap; run reads the first machine left to
right against the goal row; rings jump into the machine of their colour and come back, rings
nest, rings can loop back into the first machine; empty slots, mismatches and running out fail
the run; 64 energy, moves and runs cost one, undo is free. Eight levels; every level keeps the
original's machines (slot counts), the pieces fixed inside them and the loose tray inventory, so
the second machine and first ring arrive on level 2, fixed twin rings on 3, loose rings on 4,
double-reading rings on 5, four machines on 6, nesting on 7, the self-loop and twelve goals on 8.

**Changed.** Pieces are smaller (5×5 with a 3×3 colour on a 5-pixel slot pitch; original 6×6
with 4×4 on 6) and drawn differently (rings with a centre hole, slot dots); machine frames
resized; every piece and machine recoloured through a new colour mapping; the intended
arrangement is shuffled, so every level's goal row is a new sequence (each keeps at least the
original's number of distinct colours and ring jumps); machines are re-laid out and the tray is
re-ordered; the goal block moves; dark theme; the energy bar is the left column instead of the
tray line (a plain line still marks the tray).

**Not copied faithfully.** Level 2's one-off green line joining the ring to its machine is left
out. One render-only guard was added to the rule code so the match flash stays inside the
smaller tiles. Colour fades step through palette numbers as in the original, so with the dark
theme they pass through greys.

**Difficulty.** Stored winning lines use the same number of actions as a recorded win of the
original on every level (9, 15, 15, 15, 17, 19, 17, 17): place each needed piece, then one run.
