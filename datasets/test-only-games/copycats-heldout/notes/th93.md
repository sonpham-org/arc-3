# th93 — copy of tu93 Trail Unwind (HELD-OUT, TEST ONLY — NEVER TRAIN)

**Kept.** tu93's own class drives every step (renamed and subclassed, the 17-game package's
method): arrows move the token one pad along a wire, every press costs a step, enemies move
after you and burst or kill exactly as in the original, the green exit clears the level, the
step budget per level is the original's. Nine levels with the same enemies on the same levels.

**Changed.** Every level is turned a quarter turn clockwise; directional pieces keep facing the
same way relative to the board (their heading turns with it). Every board is reworked: dead-end
branches are grown from existing pads into empty space and wires the player never crosses are
cut, and an edit is kept only if the original's recorded winning line, turned, still clears the
level exactly on its last move. Dead ends and cuts can never shorten a route, so no level is
easier than the original; most are more maze-like (between 6 and 18 edits per level). Pads are
drawn as hollow rings; each board sits somewhere else in its view; level 4's view shrinks so the
engine draws it at twice the size; the step bar moves from the bottom row to the top row and
fills from the right; all colours reassigned (white field, purple wires, orange pads).

**Not copied faithfully / caveats.** Tile scale is unchanged on eight of nine levels: the boards
are 33–45 pixels wide, so the engine can only draw them at one pixel per cell. Token and enemy
art is unchanged because the rules read those sprites' pixels (an enemy's state flag and burst
colour). The winning line is the original's line turned, so its length per level is the
original's (18, 10, 19, 18, 29, 30, 14, 23, 29); the map around it is new.
