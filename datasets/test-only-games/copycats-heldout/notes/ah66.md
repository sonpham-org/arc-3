# ah66 — copy of as66 Always Sliding (HELD-OUT, TEST ONLY — NEVER TRAIN)

**Kept.** All rule code: blocks slide until stopped, the field wraps at its edges, enemies step
before the block slides and kill on contact, bars recolour a block that slides through them, a
block must rest in a cup whose marker is the cup colour or the block's own colour, pressing the
side the ring already shows is free, a per-level move meter loses on the move that fills it, the
winning move is free. Nine levels, and the same inventory per level as the original (the same
number of blocks, cups, marker colours, bars and their lengths, enemies and their patrol
directions), so each mechanic first appears on the same level.

**Changed.** Every map is new: different grid size, new wall clusters, every piece placed
elsewhere, cup openings re-chosen, bars re-oriented. Colour of every role moved by one fixed
permutation (floor purple → light blue, cups white → black, walls → dark red, enemies → dark
grey with an orange core, backdrop → white, …). Cell size per level differs (copy 3 3 3 3 2 4 3
2 3 against the original 4 4 4 4 3 3 4 3 2). Blocks drawn as notched tiles, enemies as hollow
frames, ring corners open. The move meter fills from the bottom centre up the sides (original:
top centre down), and the level-progress bar is on the top row (original: bottom).

**Difficulty.** Never easier than the original: the generator only keeps a map whose fewest
counted moves (found by breadth-first search through the copy's own engine) is at least the
original level's par and at most about a third above it. Fewest moves per level, copy vs
original: 3/3, 4/3, 8/7, 4/4, 15/13, 10/8, 7/7, 11/9, 12/11. Move budgets keep the original's
budget-to-par ratio.

**Not copied faithfully.** Nothing in the rules. The generator only requires an enemy level's
enemies to be able to kill within the first moves; it does not prove they block the obvious
line the way a hand-made level would.
