# Hand-off: rulediscovery1__fepInspired (OpenMind's free-energy rule-discovery agent)

Design and direction: OpenMind. Code and experiments: Bubba (Claude Opus 5.5) at OpenMind's request.
CPU only: no GPU library, no model calls (the LLM rule provider is a stub that returns nothing).

Read in this order:
1. `README.md`: architecture and the mapping to active inference (perception, rule-set posterior, expected free energy policy, goals).
2. `NOTE_currentState.txt`: newest state at the top of each section; debates three to five, what each pick changed, results, open problems.
3. `results/debate5/report.md`: the latest live-play sweep (20 seeds x 500 actions on Locksmith ls20, Warehouse wa30, Ghost Twin g50t, exact local simulators).
4. `results/replay_all_games/all_games_report.md`: NEW (06-Oct). Offline replay, one saved play per game for all 25 games
   (play with the most clears, first 600 steps), learned rule sets with posterior weight, surprise spikes, goal guesses.
   Scripts: `results/replay_all_games/all_games.py` and `one_replay.py` (run from `ARC3-Inference/` with `PYTHONPATH=.`).

Replay result in one paragraph: clean mechanics (controlled piece, step size, wall colours, push/collect contacts, click
colour changes) on ls20, bp35, dc22, g50t, ka59, sk48, wa30, sc25, tu93, with partial rules on cn04, re86, m0r0; only the
generic "same action repeats its outcome" on ar25, ft09, lf52, s5i5, sp80, tn36, vc33; counts only on cd82, lp85, r11l,
sb26, su15, tr87 (mostly click games). Goal guesses weak almost everywhere.

Known weak assumptions (see the #experimentalmessing discussion with Son, 06-Oct): one-colour blobs plus common-fate
grouping only for touching parts; one controlled self; coarse event labels lose geometry; fixed rule templates; short
context (no delayed effects or hidden counters); few kept hypotheses so weights look overconfident; one rulebook across
levels (subtle per-level changes such as ar25's are seen as surprise, not explained); goals from a fixed short list;
replay learns only from actions the player took.

Proposed use (Son, 06-Oct): run on CPU alongside the GPU player, inject only rule deltas (new confident rule, broken
rule, one probe) into the user turn, keep the rulebook outside the context so it survives turn swaps; use the learned
step size to downsample the board. Large raw files (>5 MB: results/soft/a0_*.jsonl, results/tl/s2_offline.json) were
left out; `results/game_sweep/debate5/rows.json` is gzipped. Debate scoring helpers are in `scripts_outside_package/`.
